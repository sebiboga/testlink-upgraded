# Free Test Cases Report — Modernized Screen

The **Free Test Cases** report (ASIDE → Reports → *Test Cases not Assigned to Any Test Plan*) lists all test cases in the active test project that are NOT linked to any test plan — one row per test case, grouped by test suite. It replaces the legacy 1.9.20 `lib/results/freeTestCases.php` HTML view with a modern Dashio-styled page backed by a plain-PHP REST BFF.

**Path:** ASIDE menu → Reports → *Test Cases not Assigned to Any Test Plan*
**URL:** `gui/templates/results/freeTestCases.html?tproject_id=<id>`
**BFF API:** `api/reports/index.php` — `GET ?action=free_testcases&tproject_id=N`
**Rights:** `testplan_metrics`
**Tracking issue:** [#751](https://github.com/sebiboga/testlink-upgraded/issues/751)

## 2. Data Flow and Parity

The BFF calls exactly the same engine method as the legacy controller:

1. `testproject::getFreeTestCases($tprojectId)` — fetches all test case IDs in the project, fetches those linked to any test plan, then computes the difference (free = all − linked). If no test plans exist (`allfree=true`), all test cases are returned.
2. Row post-processing: `tree::get_full_path_verbose()` resolves the test suite path; the full external ID is built from `prefix + glue + external_id`.
3. Columns match legacy: Test Suite, Test Case, Importance (shown only when priority management is enabled for the test project).
4. Table is grouped by test suite and sorted by importance (descending), same as legacy `tlExtTable` behavior.
5. Footer (Issue #1265): the BFF success payload emits `generated_on` (`date('Y-m-d H:i:s')`, same convention as `tplan_with_cf` / `metrics`), and the HTML `renderFooter(d)` helper renders `common.generatedBy + generated_on` in all three footer branches (data / warning / all-assigned). The generated-on segment degrades gracefully when the key is absent.
6. Report info (Issue #1264): in the has-data branch `loadData()` appends a localized `<p class="info reportinfo">` immediately after the results section, so the DOM order matches legacy `freeTestCases.tpl:31-38` (table → italic info → generated-on footer). BFF unchanged — the info text is presentational (new `ftc.infoReport` key).
7. ExtTable parity (Issue #1262): the grid now reproduces `lib/results/freeTestCases.php:110-118` + `getColumnsDefinition():138-150` fully client-side (the BFF already ships `suite_path` + `importance`): DataTables **RowGroup** renders the collapsible `Test Suite: <path> (N Items)` headers (`exttable.class.php:591` template) with the grouped column hidden (`exttable.class.php:55`); the **6-button toolbar** mirrors `inc_ext_table.tpl` (Expand/Collapse Groups toggles all groups, Show all Columns reveals the grouped column + its filter cell, Reset to Default State clears filters/groups/multi-sort and restores the default order, Refresh reloads via ajax); the **tfoot filters** mirror legacy `GridFilters` (text on Test Suite/Test Case, `ListSimpleMatch` list on Importance); the **default order** is suite ASC + importance DESC (test-case DESC when priorities are off) matching `setSortByColumnName(...)` + `sortDirection='DESC'` (`freeTestCases.php:112-113`), with rank-based importance sort (high=3) and zero-padded external-id test-case sort (legacy `<!-- %010d -->` prefix, `freeTestCases.php:90`); the **MultiSort** button/chips mirror the legacy Ext.ux.ToolbarDroppable drag-a-header workflow. No BFF change. Screenshots: `docs/screenshots/issue-1262-freetestcases-after.png`, `docs/screenshots/issue-1262-freetestcases-interaction.png`.

## 4. Permission Path and Empty State

- No session → 401; missing `testplan_metrics` on global role AND project context → 403
- All test cases assigned → info icon with `ftc.allAssigned` message
- No test plan exists (allfree) → data table displayed with all test cases

## 5. BFF API Reference

### `GET ?action=free_testcases&tproject_id=N`

Returns project-scoped free test cases.

```json
{
  "status": "ok",
  "tproject_id": 1,
  "tproject_name": "FTC Test Project",
  "priority_enabled": true,
  "all_free": true,
  "has_data": true,
  "rows": [
    {
      "tcase_id": 6,
      "tc_external_id": 1,
      "external_id": "FTC-1",
      "name": "TC Free 1",
      "suite_path": "Suite A",
      "importance": "high"
    }
  ],
  "warning_msg": "",
  "elapsed_time": 0.01,
  "generated_on": "2026-10-06 09:42:50"
}
```
