Security scheme
The specification declares one security scheme and the shared request rules:
  • sessionCookie (apiKey, cookie PHPSESSID) — log in through POST /api/auth/login; an anonymous caller receives HTTP 401 with code not_authenticated.
  • X-Requested-With header — every state-changing verb (POST/PUT/DELETE) must send X-Requested-With: XMLHttpRequest (shared CSRF guard) or gets HTTP 403 csrf_failed.
  • Same-origin only — state-changing routes verify Origin/Referer first - a foreign origin is refused with HTTP 403 foreign_origin.
  • Session inactivity — a stale session expires server-side and answers HTTP 401 with code session_expired.
