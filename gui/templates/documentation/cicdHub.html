Publish automated results from CI/CD
Run your automated tests anywhere — GitHub Actions, GitLab CI, Jenkins or any shell — and publish the result file to TestLink. The publish endpoint parses JUnit XML or a simple JSON structure and records the execution status against the matching test cases of a test plan.
Publish endpoint: POST /api/cicdpublish/index.php?action=publish
