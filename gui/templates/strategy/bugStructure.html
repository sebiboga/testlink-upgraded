Bug Structure the mandatory sections of a defect report (Refs #1289)
Back to Test Strategy
Mandatory sections
  • ENVIRONMENT - Operating System, browser name/version, build version, URL and other agreements from the Test Strategy.
  • STEPS TO REPRODUCE - exact reproducible steps.
  • EXPECTED RESULTS - what should happen.
  • ACTUAL RESULTS - what actually happens, with screenshots or video as evidence.
Optional sections
  • PRECONDITIONS - only when specific preconditions must be met before running the steps.
  • Screenshots added in ACTUAL RESULTS as evidence.
  • Video recording added in ACTUAL RESULTS as evidence.
  • Bug Structure is part of the Test Strategy.
